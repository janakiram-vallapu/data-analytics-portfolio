## Featured Projects

### Loan Approval Data Analysis

**Tools:** SQL, Python, Pandas, Power BI, DAX

- Cleaned, transformed, and validated a 614-record loan dataset.
- Handled missing values and inconsistencies to prepare analysis-ready data.
- Analyzed applicant income, credit history, loan amount, and demographic patterns.
- Developed an interactive Power BI dashboard with a star-schema data model, DAX measures, KPIs, slicers, and visualizations.

### HR Employee Attrition Analysis

**Tools:** Python, Pandas, MySQL, Power BI, DAX

- Analyzed 1,470 employee records to identify workforce segments associated with elevated attrition.
- Wrote 25 SQL queries using conditional aggregation, subqueries, CTEs, window functions, and ranking.
- Built a six-page interactive Power BI dashboard covering attrition, compensation, employee experience, and high-risk segments.
- Identified 64.1% attrition among employees aged 18–25 who worked overtime.
