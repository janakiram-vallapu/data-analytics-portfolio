# Loan Approval Analysis

## Project Overview

This project analyzes loan application data using Python, SQL, and Power BI. The objective is to clean and explore the data, identify factors associated with loan approval, and communicate the results through an interactive business intelligence dashboard.

The analysis covers a dataset containing **614 loan application records**.

## Project Objectives

- Clean and validate the loan application data
- Handle missing values and inconsistent records
- Perform exploratory data analysis
- Examine the factors associated with loan approval
- Build a structured data model in Power BI
- Create DAX measures, KPIs, and interactive visualizations
- Support data-driven loan analysis and decision-making

## Tools and Technologies

- Python
- Pandas
- SQL
- Power BI
- DAX
- Power Query
- Jupyter Notebook

## Project Workflow

1. Imported and inspected the loan application dataset.
2. Cleaned, transformed, and validated 614 records using Python and Pandas.
3. Handled missing values and removed data inconsistencies.
4. Prepared an analysis-ready dataset.
5. Conducted exploratory data analysis to examine:
   - Applicant income
   - Credit history
   - Loan amount
   - Demographic patterns
6. Designed a star-schema data model in Power BI.
7. Created DAX measures and KPIs.
8. Built an interactive dashboard with slicers and visualizations.
